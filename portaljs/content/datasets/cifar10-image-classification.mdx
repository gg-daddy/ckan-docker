# Overview

CIFAR-10 is a widely used benchmark dataset for image classification, consisting of 60,000 32x32 color images in 10 different classes.

The 10 classes are: airplane, automobile, bird, cat, deer, dog, frog, horse, ship, and truck. Each class has 6,000 images. The dataset is split into 50,000 training and 10,000 test images.

**Key Features:**
- 60,000 color images
- 32x32 pixel resolution
- 10 object classes
- Balanced dataset
