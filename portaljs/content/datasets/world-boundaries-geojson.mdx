# Overview

This dataset contains administrative boundary data in GeoJSON format for countries around the world. It provides ADM2 level (district/county level) boundaries suitable for geographic visualization, spatial analysis, and mapping applications.

**Key Features:**
- GeoJSON format for easy web integration
- ADM2 level administrative boundaries
- Coverage of multiple countries
- Compatible with Leaflet, MapLibre, and other mapping libraries

## Quick Start

### Using in JavaScript/React

```javascript
// Fetch GeoJSON data
const response = await fetch('/data/sample-boundaries.geojson');
const geojson = await response.json();

// Use with Leaflet
L.geoJSON(geojson).addTo(map);
```

### Using Hugging Face Datasets

```python
from huggingface_hub import hf_hub_download

# Download specific country file
file_path = hf_hub_download(
    repo_id="c1587s/adm2-geojson-dataset",
    filename="ABW_adm2.geojson",
    repo_type="dataset"
)

# Load with geopandas
import geopandas as gpd
gdf = gpd.read_file(file_path)
print(gdf.head())
```

## GeoJSON Structure

```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "properties": {
        "NAME_1": "Region Name",
        "NAME_2": "District Name",
        "TYPE_2": "Boundary Type"
      },
      "geometry": {
        "type": "Polygon",
        "coordinates": [...]
      }
    }
  ]
}
```
